Neon Bay is an original open-world crime game in the spirit of GTA 6, built as plain static files: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police through a 5-star wanted system, run five story missions for Vic and Lena, fight with fists and a pistol, and watch the day fade from golden afternoon to neon night — all rendered on canvas with synthesised WebAudio sound and no network requests at all.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
